# 자동차 G6 Stage-Gate 데모 데이터

적용 브랜치: `ui/smartsheet-workview-v2` 전용

## 구성

- 템플릿: **G6-GATE 기반 자동차 시트 원단 개발 템플릿**
- 거래처: 현대자동차, 기아자동차, 르노자동차
- 프로젝트: 현대 7개, 기아 5개, 르노 3개(총 15개)
- 산출물: 프로젝트당 30개, 총 450개 DOCX
- 운영 데이터: 프로젝트당 이슈 2개·리스크 2개·협업요청 2개, 총 90건
- Gate: G1~G6, 선행 활동 완료와 필수 산출물 승인 후에만 PASS 가능
- 후행 활동: 선행 Gate의 최신 결정이 PASS일 때만 실적 시작·등록 가능

## 전체 데이터 생성

V2 브랜치를 받은 뒤 애플리케이션의 로컬 D1 환경에서 실행한다.

```bash
git switch ui/smartsheet-workview-v2
npm install
npm run data:seed:auto-g6-all
```

명령은 고객사·프로젝트 타입·템플릿·15개 프로젝트·WBS를 만든 뒤 450개 문서를 생성/업로드하고, 실적·Gate 결정·이슈·리스크·협업요청을 등록한다. 동일 환경에서 다시 실행해도 중복 생성을 피하도록 구성했다.

## 검증

```bash
npm run test:auto-g6
npm run check:v2-ui
```

## 데모 확인 순서

1. 전사 프로젝트 대시보드에서 거래처 필터와 Gate별 누적 통과를 확인한다.
2. 프로젝트를 열어 현재 Gate, 지연 Task, 필수 산출물 미흡, 열린 이슈를 확인한다.
3. G1~G6 흐름에서 통과/검토/예정 상태를 확인한다.
4. **AI 프로젝트 브리핑**을 눌러 저장된 프로젝트 실적을 문맥으로 대화를 시작한다.
5. 산출물에서 프로젝트별 원단명, 규격, 시험값, 판정, 후속조치가 포함된 DOCX를 확인한다.
