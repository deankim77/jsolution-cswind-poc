# 코오롱 CIM 2026-08-21 데모·견적 범위 기준

## 미팅 목적

- 기술검토 범위는 CIM과 CSM이며, 1차 구축과 메인 데모는 CIM이다.
- 고객 최종 통합 요구사항 142건을 확정하고 최종 견적 산출 기준을 닫는다.
- 기존 계열 113건과 추가검토 29건으로 구성되며, 21일 우선 확정 대상은 22건이다.
- 기존 제출 견적 3.3억 원은 이전 136건 기준이다.

## 데모 원칙

데모는 CIM 전용 기능 전체가 완성되었다는 의미가 아니다. 현재 구현된 PMS + 경량 PLM 공통 기반으로 고객 요구를 얼마나 편리하게 처리할 수 있는지 보여준다.

### 시연하는 현재 기능

1. CIM 프로젝트와 End-to-End 10단계 WBS
2. Task·Role·담당자·근무일 일정·선후행·Gate
3. 간트 이동·기간 조정·후속 일정 연쇄 반영
4. MY WORK의 담당 업무와 승인대기
5. 산출물 등록·Revision·미리보기·다운로드
6. 이슈·리스크·협업요청과 조치이력
7. 프로젝트 대시보드와 통합검색
8. AI 일정 영향·회복안 미리보기·명시적 승인
9. 우측 AI와 MY AI HOME 대화·출처 연속성

### 구축 범위로 설명하는 항목

- 칼라 마스터·염료 레시피·고객 승인·회차별 승인율
- 작업지시와 염색 호기별 설비 일정
- 개발 샘플 재고·출고·위치·바코드·라벨
- 협력사 Portal·제한공유·보안로그·DRM
- 메일·Teams·그룹웨어 결재 연계
- CAD·Illustrator 자동변환과 CCM 자동연동

위 항목은 현재 공통 기능으로 대체 가능한 부분만 보여주며, 전용 모듈이 완성된 것으로 표현하지 않는다.

## 15분 권장 데모 동선

1. 프로젝트 홈과 CIM 프로젝트 개요 — 1분
2. WBS·Gate·담당자·필수 산출물 — 3분
3. 간트 지연과 AI 일정 회복안 승인 — 3분
4. Task 실적·산출물·이슈·완료 승인 — 3분
5. 문서 Revision·미리보기·통합검색 — 2분
6. AI HOME에서 대화와 출처 이어가기 — 2분
7. 142건 중 추가·연계·확정 범위 설명 — 1분

CSM R14 프로젝트는 CIM 시연 후 확장 가능성을 보여주는 보조 사례로만 사용한다.

## 견적 원칙

- 기존 136건 기준 3.3억 원을 기준 견적으로 유지한다.
- 추가검토 29건 중 기존 제안 기능 활용 항목은 기존 범위에서 검토한다.
- 신규 개발·조건부 협의·외부연계 항목은 21일 확정 결과에 따라 추가 또는 별도 견적으로 분리한다.
- 재고/바코드·Portal/DRM·외부 시스템 연계는 상세 범위와 고객 인프라 조건이 확정되기 전 총액에 포함하지 않는다.
